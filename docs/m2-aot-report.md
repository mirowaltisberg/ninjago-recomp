# M2 report: whole-library AOT build and headless boot (Task 23)

## Build
- `tools/recomp/cli.py` translates **14 118** ARM functions into 64 C files (`build/gen/`, generated by CMake from the
  `.so`, never committed); 6 become loud stubs: `__gnu_Unwind_{Save,Restore}_{VFP,WMMXD,WMMXC}` (C++ exception
  unwinding only, iWMMXt/FLDMX coprocessor instructions). The whole library compiles in about 24 s, warning-free.
- Thumb code is never translated: ARM code calls 6 Thumb runtime helpers and the start-up runs 2 Thumb static
  constructors; all 8 are host overrides (byte-checked where unnamed). Any other Thumb target fails loudly.

## Verification
| Check | Result |
|---|---|
| difftest (every instruction shape, 64 random states each, vs Unicorn) | 2600 cases, 0 failing, bit-exact incl. NaN payloads |
| funcdiff (300 self-contained functions, random arguments, vs Unicorn) | 293 tested, 0 failing (7 never got a valid input) |
| test_aot_divide (libgcc 32/64-bit division helpers on AOT) | pass |
| headless boot, 600 frames (`--fixed-clock`, tap at 300) | no fatal, same draw counts as Unicorn |
| headless 1500 frames at 60 fps, taps at 600/900 (menus) | no fatal, draw counts identical at every checkpoint |

Boot bugs found and fixed on the way (each with a regression test): Thumb static constructors in `.init_array`
(overrides), functions whose entry is not their lowest address (`__aeabi_uidivmod`: emit a goto to the entry),
callbacks addressed only relative to pc (discovery now follows `ldr rX, =off; add rY, pc, rX` and adr; 8 entries).

## Trace comparison (`tools/tracediff.py`, 600 frames)
- Loader, worker and one-shot threads: identical call for call (1652, 3004, 1 calls).
- Main thread: identical for the first 7066 HLE calls; the first difference is a non-argument register value
  in `pthread_mutex_unlock` (loader progress read under a lock) and the following calls match again. Later
  differences come from the timing between the main thread and the loader/audio threads, which runs about 9x
  faster on AOT.

## Speed (headless, no real GL)
25 s of menu frames at 60 fps: Unicorn 1.76 s user CPU, AOT 0.19 s (about 9x less). Gameplay frames do far more
guest work, so the gain there is larger.
