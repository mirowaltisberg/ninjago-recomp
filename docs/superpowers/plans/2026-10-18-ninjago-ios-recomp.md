# LEGO Ninjago Tournament iOS Recompilation: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the Android build of LEGO Ninjago: Tournament (`libLEGO_M1.so` 1.05.2, ARMv7) natively on iOS 27 by recompiling its machine code to arm64 ahead of time and replacing the Android platform layer.

**Architecture:** The guest library is loaded into a 32-bit guest address space inside a 4 GiB host reservation. One platform layer ("HLE": bionic libc subset, pthreads, EGL/GLES2, OpenSL ES, JNI with emulated Java methods) serves two interchangeable CPU backends: Unicorn (macOS only, for bring-up and as the reference oracle) and AOT, which is C generated by a Python/Capstone recompiler and compiled to arm64. M0–M2 run headless on macOS. M3–M6 add the iOS app.

**Tech Stack:** C11 (runtime/HLE), Objective-C (iOS shell, later), Python 3 + capstone 5.0.7 + pyelftools + pytest (recompiler), unicorn 2.1.4 (C API via Homebrew), CMake + Ninja + CTest, jadx (one-off Java decompile), Xcode 27.1 / iOS 27.1 SDK.

**Spec:** `docs/superpowers/specs/2026-10-18-ninjago-ios-recomp-design.md`

## Global Constraints

- Never commit or push game files or generated translations: `input/`, `gen/`, `build/`, `*.so`, `*.obb`, `*.fib`, `*.apk`, `*.xapk`, `*.ipa` stay ignored (already in `.gitignore`). Tests that need the real library or OBB **skip** when `input/extracted/...` is absent.
- Guest input paths: library `input/extracted/lib/armeabi-v7a/libLEGO_M1.so`; OBB `input/extracted/Android/Obb/com.lego.ninjago.toe/main.1057.com.lego.ninjago.toe.obb` (extract with `unzip` from `input/ninjago-android-1.05.2.xapk`).
- Guest memory map (`runtime/include/nj/guest.h`, used verbatim by the recompiler via `--base`):
  `NJ_IMAGE_BASE 0x00100000` · `NJ_HLEDATA_BASE 0x01000000` (16 MiB) · `NJ_HEAP_BASE 0x02000000`, `NJ_HEAP_SIZE 0xDE000000` · `NJ_STACK_BASE 0xE0000000`, 1 MiB per thread, max 256 · `NJ_THUNK_BASE 0xF0000000` (8 bytes per thunk) · `NJ_RETURN_TRAP 0xFFFF0000`. Guest page 0–0xFFFF is never mapped.
- Guest ABI: AAPCS **softfp** (float/double args and returns in core registers; doubles in even/odd pairs r0:r1, r2:r3, or 8-byte-aligned stack slots).
- Guest C library is **bionic 32-bit ARM**: struct layouts below are bionic's, not Darwin's.
- Unknown imports, unimplemented JNI slots and dispatch misses must fail loudly through `nj_fatal()` naming the symbol/address. Never return silent zeros from unknown functions.
- Debug builds compile generated C with `-O1 -g`; release `-O2`. All C is warning-clean under `-Wall -Wextra`.

## Review Focus

1. **Doubles in guest varargs** (`snprintf("%f")`, JNI `Call*Method` with float args promoted to double): must read 8-byte-aligned slots, skipping a register or stack word. → test in Task 8 and Task 13.
2. **OBB entry offsets** passed to the engine must point at file *data*, past the local zip header (30 + name length + extra length, where extra in the local header may differ from the central directory). → test in Task 10.
3. **Huge file reads/mmaps** (`.fib` files up to 301 MB): mmap/fread of large ranges must succeed and return the correct last bytes. → test in Task 9.
4. **Float→int conversion edge cases** (`vcvt.s32.f32` of NaN, ±3e9): ARM saturates (NaN→0, 3e9→0x7FFFFFFF, −3e9→0x80000000); a C cast is undefined behaviour. → test in Task 21.
5. **Guest atomics across threads** (`ldrex/strex` loops on shared counters from loader + main thread): no lost updates. → stress test in Task 20.

### Task 9: File system, stdio, fd and mmap
